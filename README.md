# 🎬 Movie Recommender System

A full-stack movie recommendation web application built using **TF-IDF Vectorization**, **Cosine Similarity**, **FastAPI**, **Streamlit**, and the **TMDB API**.

The system recommends similar movies based on textual metadata such as genres, keywords, cast, and overview using a content-based recommendation approach.

---

## 🚀 Features

* 🔍 Search movies using TMDB API.
* 🎬 View movie details including:

  * Poster
  * Release date
  * Rating
  * Genres
  * Overview
* 🤖 TF-IDF based movie recommendations.
* 🎭 Genre-based recommendations using TMDB.
* 🏠 Home feed:

  * Trending
  * Popular
  * Top Rated
  * Upcoming
  * Now Playing
* ⚡ FastAPI backend.
* 🎨 Streamlit frontend.
* 🌐 TMDB integration for posters and metadata.

# 🧠 Recommendation System

The recommendation engine uses:

* **TF-IDF Vectorizer**
* **Bi-grams (ngram_range=(1,2))**
* **Cosine Similarity**

```python
tfidf = TfidfVectorizer(
    stop_words='english',
    ngram_range=(1,2),
    max_features=50000
)

tfidf_matrix = tfidf.fit_transform(df['tags'])
```

Recommendations are generated by calculating cosine similarity:

```python
similarity_scores = cosine_similarity(
    tfidf_matrix[idx],
    tfidf_matrix
).flatten()
```

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/movie-recommender.git

cd movie-recommender
```

---

## 2. Create Virtual Environment

```bash
python -m venv venv
```

Activate:

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Get TMDB API Key

Create a TMDB account and generate an API key.

Create a `.env` file:

```env
TMDB_API_KEY=your_api_key_here
```

---

# ▶️ Run Backend

```bash
uvicorn app:app --reload
```

Backend runs at:

```text
http://127.0.0.1:8000
```

# ▶️ Run Frontend

```bash
streamlit run main.py
```

```text
http://localhost:8501
```
